# RO’Lyfe Entertainment Media Gateway™ (EMG)

**Know the past. Master the present. Build the future.**

A family-oriented entertainment and learning gateway. Open `index.html` or publish the repository root through GitHub Pages.

## Initial release
- Eight selectable themes and local preferences.
- Educational reading links and history lessons.
- YouTube video library with local favorites.
- Browser read-aloud, subject to device support.
- Entertainment destination links.

## Pending integration
Original banner asset, verified radio stream, embedded live sports, cloud Atlas, casting and full educational curriculum. External video availability depends on publishers. No accounts or API secrets required for the initial static release.

`backup/pre-emg-build` preserves the original repository state.
